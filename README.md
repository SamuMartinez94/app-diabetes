#   App Control de bombas Diabetes

Aplicación de soporte desarrollada en **Flutter** diseñada para ayudar a usuarios de bombas de insulina y sensores de glucosa. La app ofrece guías visuales paso a paso y un sistema de diagnóstico para la resolución de errores comunes sencillos.

---

## Características Principales

**Tu selección:** Selección de bomba, sensor y catéter para adaptar las instrucciones a los dispositivos específicos del usuario.
**Guías de Recambio:** Tutoriales para el cambio de catéter y sensor.
**Árbol de Diagnóstico de Errores:** Un flujo de decisiones interactivo que guía al usuario a través de preguntas para solucionar alertas de los dispositivos.
